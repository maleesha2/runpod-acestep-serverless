# ComfyUI ACE-Step for RunPod Serverless

[![Runpod](https://api.runpod.io/badge/maleesha2/runpod-acestep-serverless)](https://console.runpod.io/hub/maleesha2/runpod-acestep-serverless)

This repository provides a Dockerized environment for running the ACE-Step music generation model via ComfyUI as a RunPod Serverless endpoint.

## Architecture
The Docker container builds a fully self-contained environment:
1. Base image: `runpod/pytorch` with CUDA 12.1.
2. Clones the ComfyUI repository.
3. Clones the `ACE-Step-ComfyUI` custom nodes.
4. Downloads the ACE-Step models via HuggingFace during the Docker build process.
5. Runs a Python `handler.py` script that starts ComfyUI locally inside the container and accepts RunPod API JSON inputs to trigger generations.

## How to Build and Deploy

### 1. Build the Docker Image Locally
```bash
docker build -t your-dockerhub-username/runpod-acestep:latest .
```

### 2. Push to a Container Registry
You need to push this image to a registry like Docker Hub so RunPod can pull it.
```bash
docker push your-dockerhub-username/runpod-acestep:latest
```

### 3. Deploy on RunPod Serverless
1. Log into your RunPod account and go to the **Serverless** dashboard.
2. Click **New Endpoint**.
3. Fill in the required details:
    * **Endpoint Name**: e.g., `acestep-music-gen`
    * **Template**: Create a new template and provide your Docker image tag: `your-dockerhub-username/runpod-acestep:latest`
    * **Container Registry Credentials**: (If your repo is private)
4. Choose the GPU types you want to use (e.g., RTX 4090 or A100 is recommended for fast generation).
5. Deploy.

## How to Use the API

Once deployed, RunPod will provide an API URL. You can send requests to it using the RunPod Python SDK or standard REST requests.

**Payload Structure:**
The endpoint expects a ComfyUI workflow JSON within the `input.workflow` key.

```python
import runpod

runpod.api_key = "YOUR_RUNPOD_API_KEY"
endpoint = runpod.Endpoint("YOUR_ENDPOINT_ID")

# Load your ComfyUI workflow JSON that utilizes the ACE-Step nodes
import json
with open("ace_step_workflow.json", "r") as f:
    workflow = json.load(f)

# Send request
run_request = endpoint.run({"workflow": workflow})

# Get results
result = run_request.status()
print(result)
```

The output will contain the base64 encoded audio generated by ComfyUI.
